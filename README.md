# uDRM (Micro Direct Rendering Manager)

A lightweight, modular, and portable Micro Direct Rendering Manager (uDRM) designed specifically for custom operating systems and hobbyist OSDev projects.

## Collaboration

This project is a joint effort maintained by:
* **[Equinox Collective](https://github.com/Equinox-Collective)**
* **[Hidotu Labs](https://github.com/Hidotu-Labs)** (represented by [@Offhito](https://github.com/Offhito))

## Features (Planned)
* Lightweight framebuffer and display pipeline abstraction.
* Simple memory management interface for graphics buffers.
* Highly portable codebase with minimal dependencies on host kernels.
* Modular drivers for common OSDev display targets (e.g., Bochs VBE, VirtIO-GPU, simple framebuffers).
